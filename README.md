# SDT VideoClass

Web app para la academia de baile Son de Timba. Permite a estudiantes ver los
cursos que están tomando, reproducir videos de clase, comentar sobre la clase y
enviar preguntas al profesor con adjuntos de imagen o video.

## Funcionalidades

- Catálogo de cursos activos con progreso del estudiante.
- Reproductor de videos por clase.
- Comentarios asociados al video seleccionado.
- Formulario para enviar preguntas al profesor.
- Adjuntos de imagen o video para recibir review del profesor.
- Panel del profesor con las preguntas recibidas por curso.

## Stack

- React
- TypeScript
- Vite
- ESLint

## Desarrollo

Instala dependencias:

```bash
npm install
```

Inicia el servidor local:

```bash
npm run dev
```

Verifica lint:

```bash
npm run lint
```

Genera build de producción:

```bash
npm run build
```
